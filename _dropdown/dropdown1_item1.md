# Tools I've created
## Fakeroot - [GitHub](https://github.com/Henryisnotavailable/Fakeroot)
A _very_ simple tool to exploit writable /etc/passwd or /etc/shadow files.
## eMudhra CA Compromise - [GitHub](https://github.com/Henryisnotavailable/eMudhra-CA-Compromise)
A script which proves the eMudhra compromise. It "brute forces" the keys, and then creates a forged certificate of your choosing. The certificate should show as revoked (as long as your browser is up to date).
## Macro Libre - [GitHub](https://github.com/Henryisnotavailable/Macro-Libre)
Python script to create malicious Libreoffice documents that run macros to execute system commands on document open.
## CVE-2018-16858 - [GitHub](https://github.com/Henryisnotavailable/CVE-2018-16858-Python)
Python implementation of CVE-2018-16858 Based on work from [here](https://insert-script.blogspot.com/2019/02/libreoffice-cve-2018-16858-remote-code.html) and [here](https://www.exploit-db.com/exploits/46727)
## Turtler - [GitHub](https://github.com/Henryisnotavailable/CTF-Scripts/blob/main/turtler.py)
A basic script to facilitate the easy generation of reverse shells using various encoding.
